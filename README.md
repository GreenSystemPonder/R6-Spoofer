# R6 Spoofer

Download: soon

Rainbow Six Siege hardware ban spoofer for Windows 10/11. BattlEye ties the ban to several identifiers, all of them are rewritten here.

**Included:** disk and volume serials, MAC, SMBIOS UUID, board serial, machine GUID, computer name.

**Excluded:** account data, game files, Ubisoft Connect install.

## Using

Open the exe as administrator. Leave all boxes checked and press Spoof. The tool logs each write and asks for a reboot. After that, a new Ubisoft account is needed.

Restore puts the identifiers back and is safe to run anytime.

> Borderline components such as the volume ID are optional if another tool already changed them.
